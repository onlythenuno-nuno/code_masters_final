HTML

HTML (HyperText Markup Language) foi criado por Tim Berners-Lee em 1991 enquanto trabalhava no CERN. A linguagem foi desenvolvida para facilitar a compartilhamento de documentos científicos entre pesquisadores. A primeira versão pública do HTML foi lançada em 1993 e desde então evoluiu significativamente, com o HTML5 sendo a versão mais recente.

CSS

CSS (Cascading Style Sheets) foi proposto por Håkon Wium Lie em 1994 enquanto trabalhava com Tim Berners-Lee no CERN. A primeira especificação oficial (CSS1) foi lançada em 1996 pelo W3C. CSS foi criado para separar o conteúdo (HTML) da apresentação, permitindo designs mais sofisticados e consistentes na web.

JavaScript

JavaScript foi criado por Brendan Eich em apenas 10 dias em maio de 1995 enquanto trabalhava na Netscape. Originalmente chamado de Mocha, depois LiveScript, finalmente foi renomeado para JavaScript para aproveitar a popularidade da linguagem Java. Apesar do nome, JavaScript não tem relação direta com Java. Tornou-se fundamental para a web moderna com o advento do AJAX e frameworks como jQuery, Angular, React e Vue.js.

PHP

PHP (Personal Home Page, agora PHP: Hypertext Preprocessor) foi criado por Rasmus Lerdorf em 1994. Inicialmente era um conjunto de scripts Perl para rastrear visitas ao seu currículo online. Em 1995, ele lançou a primeira versão pública (PHP/FI). PHP se tornou extremamente popular para desenvolvimento web, alimentando sistemas como WordPress, Facebook (inicialmente) e Wikipedia.
